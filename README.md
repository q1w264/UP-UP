# UP UP!

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)
[![Made with Unity](https://img.shields.io/badge/Made%20with-Unity-57b9d3.svg?style=flat&logo=unity)](https://unity3d.com)


*UP UP!* is an open-source 2D platformer game built with **Unity 6.3 LTS** and **C#**.

## Features
- Controller support

## Tech Stack
- Unity 6.3 LTS
- UI Toolkit
- Input System
- SO Event System

## Getting Started
### Prerequisites
- Unity Hub
- Unity Editor Version: **6000.3.20f1**
- Git

### Open the Project
```shell
git clone https://github.com/q1w264/UP-UP
cd UP-UP
```
Then open the project in Unity Hub.
